# Pro Web Design Order Tags & Labels for WooCommerce

Organise WooCommerce orders with colour-coded tags. Assign tags manually, then find and manage
tagged orders from the Orders list.

When order status alone is not enough — "waiting on supplier", "fragile", "call before delivery" —
tags give you a second layer of information that is visible at a glance in the orders list.

## Features

- Colour-coded tags, created and managed from the WooCommerce admin
- A Tags column in the Orders list
- Tags on the order edit screen
- Works with WooCommerce High-Performance Order Storage (HPOS)
- Works with WooCommerce Subscriptions

## Installing

Install from the WordPress plugin directory — search for "Pro Web Design Order Tags & Labels",
or download it here:

**https://wordpress.org/plugins/pro-web-design-order-tags-labels-for-woocommerce/**

Requires WordPress 6.2 or newer, PHP 7.4 or newer, and WooCommerce.
